# Как внести вклад

Спасибо за интерес к EasyGameTranslator.

## Ошибка или идея

Сначала создайте Issue и приложите:

- версию Windows и название игры или приложения;
- шаги для воспроизведения;
- ожидаемый и фактический результат;
- снимок экрана или короткое видео, если они помогают понять проблему.

Не публикуйте ключи, токены и другие личные данные.

## Изменение кода

1. Сделайте fork репозитория.
2. Создайте ветку от актуальной `main`.
3. Внесите одно логически законченное изменение.
4. Выполните `dotnet build -c Release`.
5. Откройте pull request и заполните шаблон.

Не отправляйте сгенерированные папки `bin`, `obj`, `release-*` и `publish*`.
Все изменения рассматривает владелец проекта. Pull request может быть принят,
отправлен на доработку или закрыт.
